# Vendored SVG icons

The SVG files are copied unchanged from these published npm archives. Each file's
archive path is `package/icons/<filename>.svg`; the archive URLs pin the exact
source releases.

| Local directory | Package | Published archive | Selected SVGs |
| --- | --- | --- | --- |
| `assets/icons/simple-icons/` | Simple Icons 16.32.0 | [simple-icons-16.32.0.tgz](https://registry.npmjs.org/simple-icons/-/simple-icons-16.32.0.tgz) | `github.svg`, `bluesky.svg`, `discord.svg`, `zenn.svg`, `qiita.svg`, `note.svg`, `x.svg` |
| `assets/icons/lucide/` | lucide-static 1.48.0 | [lucide-static-1.48.0.tgz](https://registry.npmjs.org/lucide-static/-/lucide-static-1.48.0.tgz) | `mail.svg`, `house.svg`, `link.svg`, `book-open.svg`, `rss.svg` |

`simple-icons-LICENSE.md` (CC0 1.0) and `simple-icons-DISCLAIMER.md` are the
unmodified files from Simple Icons 16.32.0. Its `package/data/simple-icons.json`
does not specify an individual `license` for any of the seven selected brand
icons. The package's CC0 license does not clear trademark or other third-party
rights; see the included disclaimer and each brand's current guidelines.

`lucide-static-LICENSE` is the unmodified license from lucide-static 1.48.0. It
contains the Lucide ISC notice and the Feather MIT notice. Among the selected
icons, its Feather-derived icon list includes `link` and `rss`.

Simple Icons 16.32.0 has no dedicated Hatena Blog icon or Twitter bird icon.
`hatenabookmark.svg` belongs to Hatena Bookmark and is not included here; the
current X logo is `x.svg`.
